# Software FJ

Aplicacion de consola en Python para gestionar clientes, servicios y reservas.

## Uso

Ejecuta `python fase4.py` desde esta carpeta. El menu permite registrar y
consultar clientes, consultar, agregar, modificar o eliminar servicios, crear
reservas y cancelar reservas activas. Al eliminar un servicio, se retira del
catalogo y de nuevas reservas, pero su historial de reservas se conserva. La
primera ejecucion incluye servicios iniciales para reservas de salas, alquiler
de equipos y asesorias especializadas.

La informacion se guarda localmente en `software_fj_datos.json`, junto al
programa. No requiere instalar paquetes adicionales.
